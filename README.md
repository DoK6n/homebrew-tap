# DoK6n Tap

## How do I install these formulae?

`brew install dok6n/tap/<formula>`

Or `brew tap dok6n/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dok6n/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
